- Deploys take ~30–120s; there can be a queue after many pushes. Confirm a deploy landed

## Key gotchas to remember
- **No `"type":"liquid"`/`custom_liquid` in section schemas** (breaks the whole section → 404, silently).
- **Empty setting checks**: use `{% if section.settings.x != blank %}` (empty string is truthy in Liquid).
- **Icons have no generic size rule**: when rendering `{% render 'icon' %}` somewhere new, size both the
  `.icon` span and `.icon svg` or it renders huge.
- **Header menu source** is "navigation" on live — theme mega-menu edits only show if it's "theme".
- Git shows LF→CRLF warnings on Windows; harmless.
